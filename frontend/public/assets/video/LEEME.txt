CÓMO GENERAR LOS SUBTÍTULOS (.vtt) CON GEMINI
Desde la carpeta backend/ (usa GEMINI_API_KEY de backend/.env):
  npm run subtitulos -- ../frontend/public/assets/video/IMG_7890.MOV ../frontend/public/assets/video/bienvenida.vtt
  npm run subtitulos -- ../frontend/public/assets/video/YouCut_20261106_001829818.mp4 ../frontend/public/assets/video/modulo-1.vtt
  npm run subtitulos -- ../frontend/public/assets/video/YouCut_20261106_010031608.mp4 ../frontend/public/assets/video/modulo-2.vtt
Revisa el .vtt generado (es un borrador): corrige palabras y tiempos si hace falta.
Formato de cada subtítulo:
    00:00:00.000 --> 00:00:04.500
    Teo: Texto que se dice.
El botón «Transcripción» se arma solo con el mismo .vtt.

Si un .MOV no se ve en Chrome/Firefox (formato HEVC del iPhone), conviértelo a MP4 (H.264 + AAC):
  ffmpeg -i IMG_7890.MOV -c:v libx264 -pix_fmt yuv420p -c:a aac -movflags +faststart bienvenida.mp4
